Agent mode。コード変更は docs 追記のみ（ソースコードは変更しない）。

このコマンドに続けてユーザーが書いた内容から、次を読み取る：
- 対象（TODO 項目名 / REQ 名）
- コミットハッシュ
- 結果（OK または NG）
- 確認項目（あれば。省略時は該当 REQ の完了条件チェックリスト全項目を確認したものとして扱う）

## 結果が OK の場合
1. `docs/tasks/REQ-（対象）.md` があれば、決定事項ログに1行追記する（日時は必ず `Get-Date -Format "yyyy-MM-dd HH:mm"` で取得。「ユーザー確認」と明記）
2. `docs/TODO.md` の完了済み行に「実機検証クローズ」を追記し、`最終更新:` を更新
3. **永続正本同期**: `docs/DOCS-GUIDE.md`「永続正本同期表」または該当 REQ の同期節に従う（例: キャプチャ関連なら `SCENE-CATALOG.md` を同一コミットで更新）
4. コミット（push はしない）
5. ユーザーが同じメッセージで次のタスクも依頼していれば、上記の docs 追記・コミットを終えてから対応する

## 結果が NG の場合
1. 原因調査は行わず、まず `docs/tasks/REQ-（対象）.md`（あれば）または `docs/TODO.md`「既知の問題・メモ」に NG の内容（期待 / 実際 / 再現手順）を記録する
2. 記録した内容をもとに修正方針を提示する
3. 承認を得るまで次のタスクには進まない
