# AI 開発ルール (AI Development Rules)

> **Cursor 移行後の正本**: プロジェクトルールは `.cursor/rules/` を参照してください。
> このファイルは人間向けの要約です。

## 1. Git コミット

ワークスペースを書き換えた場合は、タスク完了報告の前に必ずコミットする。

詳細は `.cursor/rules/git-commit.mdc` を参照。

- PowerShell では `git add` と `git commit` を別ステップで実行（`&&` 不可）
- コミットメッセージ: `feat/fix/chore: 変更内容の要約`
- `git push` はユーザーが明示的に依頼した場合のみ

## 2. 無断リファクタリングの禁止

キャプチャ・OCR・外部 API 通信・タイミング依存処理など、デリケートなコードをユーザーの承認なしに整理・最適化しない。

改善案に気づいた場合は、実装前にユーザーへ提案し、承認後に独立した変更として実施する。

## 3. 変更の事前共有

大きな変更（ファイルの追加・削除・仕様変更）は、実装前に意図と変更範囲を日本語で共有し、承認を得てから着手する。
