■ 根本原因（修正対象）
raceGraphBuilder.ts assignStackLevels の xStaggerOnly 衝突条件（502行付近）:

  if (expanded && xStaggerOnly) {
    if (!xOverlap) return false;
    return yOverlap || Math.abs(baseY - p.baseY) < hitHeight;  // ← バグ
  }

Math.abs(baseY - p.baseY) < hitHeight が stack 段数に関係なく常に効く。
X 重なり + 近接 speed（baseY 差 < 14px）では段を上げても衝突が解消されない。
→ STACK_ASSIGN_MAX_ITER(256) 打ち切り → hasSkillLabelOverlaps が常に true
→ zoom 探索が常に cap / need >20（画面は読めるのに探索だけ失敗）

■ 次の作業: Step 1（最優先）

【案 A 推奨】baseY 近接だけでは conflict にしない:

  if (expanded && xStaggerOnly) {
    if (!xOverlap) return false;
    return yOverlap;
  }

【案 B】近接 speed を同一段に限定:

  return yOverlap || (capped === p.stackLevel && Math.abs(baseY - p.baseY) < hitHeight);

実装後 npm run tauri dev で dev 表示確認:
- (cap → need X.XX) が 5〜20 内に分散するか
- ON 時の視覚的被りが悪化しないか
