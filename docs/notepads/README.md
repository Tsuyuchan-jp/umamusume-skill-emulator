# Notepad 代替ドキュメント

Cursor の **Notepads 機能は v2.0 以降で廃止** されています（Cursor 3.x では利用不可）。
本ディレクトリは、旧 Notepads と同じ「必要なときだけ AI に渡す再利用可能なコンテキスト」として使うための置き場です。

## 新チャットでの参照方法

チャット入力欄で `@` を入力し、ファイル名の一部を打つと候補が出ます。

```
@REQ-001-secure-api-key-storage.md
```

またはフォルダごと:

```
@docs/notepads
```

## ファイル命名規則

| プレフィックス | 用途 | 例 |
|---|---|---|
| `REQ-` | 要件定義（新機能・改修） | `REQ-001-secure-api-key-storage.md` |
| `ARCH-` | アーキテクチャ・設計メモ | `ARCH-001-ocr-pipeline.md` |
| `NOTE-` | 作業メモ・調査結果 | `NOTE-001-gemini-model-comparison.md` |

## 書き方のコツ（旧 Notepads ベストプラクティス）

1. **1ファイル = 1テーマ** — 複数機能を1つにまとめない
2. **見出しで構造化** — AI が必要な箇所を素早く拾えるようにする
3. **関連ファイルを `@` で列挙** — 実装時にコードを探しやすくする
4. **常時適用したいルールは `.cursor/rules/` へ** — ここは「必要なときだけ参照」用

## Rules との使い分け

| | `.cursor/rules/` | `docs/notepads/` |
|---|---|---|
| 適用タイミング | 常時 or ファイル種別に自動 | `@` で明示参照したときだけ |
| 向いている内容 | コーディング規約、Git方針 | 要件定義、PRD、設計メモ |
| Git 管理 | あり | あり |
