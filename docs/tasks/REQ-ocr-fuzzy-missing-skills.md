## 解くべき問題と目的（Problem Framing）

- **現状の課題**: 実機 OCR 後、所持スキル一覧に「千鍛万錬」「快速」が載らないことがある（ユーザー報告）
- **目的**: OCR 欠落とファジーマッチ失敗を切り分けたうえで、両スキルが OCR → 一覧（必要なら sim）に載るようにする

## 調査結果（2026-08-10）

### パイプライン（用語）

```
結合画像 → Gemini OCR（生の skills 文字列配列）
         → 診断ヘルパー（buildOcrSkillDiagnostics・読み取り専用）
         → fuzzyMatchSkillId（umasimSkillNames と類似度比較）
         → sanitizeSkillIds → SkillPanel 一覧
```

- **ファジーマッチ**（`fuzzyMatchSkillId`）: OCR 文字列とローカルスキル名一覧の類似度を取り、閾値 **0.45 未満**は空文字（＝一覧から除外）
- **正本データ**: マッチは `umasimSkillData.ts`（＝ umasim `skill_data.txt` 由来）。`skillRarityData`（mdb）は表示色用で、ID 解決には使わない

### スキル別

| スキル | mdb（`text_data` cat=47） | umasim / `umasimSkillData` | 完全一致のマッチ | 結論（現時点） |
|--------|---------------------------|----------------------------|------------------|----------------|
| 千鍛万錬 | ID `204031` | あり（rare） | rating 1.0 → 通る | **実機**: `千銀万錬` 誤読で除外（rating 0.33）。B0 エイリアスで対応 |
| 快速 | ID `202552` | あり（normal） | rating 1.0 → 通る | **実機当該回は採用成功**。たまに落ちる程度。B0 では未対応 |
| 逃げためらい | ID `200851` | **無し**（上流にも無し） | 最良 0.29 → 除外 | **本 REQ スコープ外**（下記「やらないこと」） |

### ファジー感度（机上プローブ）

`string-similarity` + 閾値 0.45・アプリ同等の空白正規化で計測。

| OCR 想定入力 | 最良一致 | rating | 0.45 通過 |
|--------------|----------|---------|-----------|
| 千鍛万錬 | 千鍛万錬 | 1.00 | ○ |
| 千鍛万練 / 連 | 千鍛万錬 | 0.67 | ○ |
| 千段万錬（鍛→段） | 千鍛万錬 | **0.33** | **×** |
| 千銀万錬（鍛→銀） | 千鍛万錬 | **0.33** | **×** |
| 快速 | 快速 | 1.00 | ○ |
| 快足 / 快遠 | （不一致） | 0 | × |

**示唆**: 「千鍛万錬」は **鍛→段** のような1文字誤読でも落ちる。完全一致なら落ちない → 実機で落ちているなら、生 OCR に正しい名前が無い／誤読されている可能性が高い。

### 実機切り分け結果（2026-08-10）

- 生スキル数 79。`千銀万錬`（#65）→ 最良「千鍛万錬」rating 0.333 で除外 → **誤読マッチ失敗**
- `快速`（#36）→ 採用成功。ユーザー所見: たまに落ちる程度
- `逃げためらい` → 除外（想定どおり・スコープ外）
